# Smart Goals Feature

## Overview
We want to leverage AI to build a seamless, delightful goal-setting experience that empowers our users to plan for the future. This is a robust feature that will unlock significant engagement and elevate the app to best-in-class.

## Users
All users of the app will benefit from this. Anyone who wants to save money can use it.

## Features
- Users can create goals
- AI suggestions
- Notifications and reminders etc
- Sharing with family, and more

## Success
We expect engagement to go up and more users to sign up. Downloads should increase as well.
